## Metadata

- `title` and `description` become the title and description for Google and social: keep the description around 150-160 characters.
- `date` uses the `YYYY-MM-DD` format; add `updated` when you revise the content.
- `translations` links the version in the other language (file slug, without `.mdx`).

## Text

Write plain markdown. Use `##` for sections and `###` for subsections: the page renders the `#` title.

> Quotes are highlighted like this.

### Code

```ts
export function hello(name: string) {
  return `Hello ${name}`;
}
```
